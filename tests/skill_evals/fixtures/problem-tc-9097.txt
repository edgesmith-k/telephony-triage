TC 6.4 Wi-Fi 통화 → LTE 핸드오버 (문장형 결과)

시험 장비: 모의 망 시뮬레이터 + 모의 Wi-Fi AP. 시각은 장비 시계 기준.

1. Wi-Fi에 연결하고 Wi-Fi 통화(VoWiFi) 등록이 되는지 확인한다. (16:02:10) → Pass
2. Wi-Fi 통화로 장비 번호에 발신해 통화를 연결한다. (16:02:40) → Pass
3. 통화 중 Wi-Fi AP 신호를 점점 약하게 만들어 통화가 LTE로 넘어가는지 확인한다. (16:03:30) → Fail (LTE로 넘어가지 않고 통화가 끊김)
4. 통화 종료 후 LTE에서 VoLTE 재발신. → 진행 안 함
