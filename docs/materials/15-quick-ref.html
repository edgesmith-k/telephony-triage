로그는 항상 파일 경로로.

처음 연습

analyze ABC-1 ~/logs/radio.txt --dry-run
아무것도 올리지 않음.

리포트에서 먼저 볼 것

  1. 분류 후보: 카테고리 > 유형 > 원인. "원인 미확인" = 증상만 맞음
  2. 근거 로그: 판정에 쓴 줄. 직접 확인
  3. 로그 범위: "범위 밖" ≠ "매칭 없음"
  4. 수정 상태: 회귀 의심·수정 미흡 의심 확인

점수는 확신도가 아님. Claude 칸은 설명일 뿐.
