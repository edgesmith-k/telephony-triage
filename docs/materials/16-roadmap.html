4진행 방법

이 절에서 알 수 있는 것: 단계를 시작하고 끝내는 방법

  1. 사내 PC에 반입 묶음을 풀고 SITE_PROFILE.md를 만든 뒤 "사내 보완 모드로 S-1 시작"이라고 합니다.
  2. 각 단계는 새 세션에서 python3 tools/context_pack.py S-n 출력만 읽고 진행합니다. 설계 문서 전체를 다시 읽지 않아 토큰이 적게 듭니다.
  3. 단계가 끝나면 완료 기준 점검 → 요약 → 사용자 확인 → SITE_PROFILE.md 진행 상태 갱신. 확인 전에는 다음 단계로 가지 않습니다.
  4. 사내 값과 사내 코드는 정해진 경로(SITE_PATHS)에만 둡니다. 다음 반입 때 보존됩니다.
