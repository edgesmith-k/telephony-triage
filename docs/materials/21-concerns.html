로그가 바뀔 때

고민같은 버전(예: Android 17)인데 버그로 판단 근거 줄이 사라지면

판단
보통은 시그니처가 안 맞아 "후보 없음"으로 가고 아무도 모른다. 줄이 없음에 기대는 시그니처(must_not_match)는 그 줄이 사라지면 잘못 분류될 수도 있다(B 리뷰에서 확인). 회귀 검증은 저장된 예전 로그와 비교해서 못 잡는다. verify-fix는 흔적이 필수라 거짓 "고쳐짐"은 막는다
보완
A 모듈 문서에 대체 근거 B 이슈 DB 작성 지침(다른 층 줄로 시그니처 하나 더(OR) — 증상 시그니처도 같은 줄에 기대면 둘 다, 대체 줄은 같은 슬롯·창 안; 없음에 기대는 근거는 "일어났음" 줄을 must_not_match에 하나 더) + db_lint --advice 참고 알림(관문에 안 듦) C′ 분석 때 부분 일치·없는 줄 표시와 시그니처 추가 제안 C 정기 점검에서 "자주 맞던 시그니처 0건" 감지 — DB 업데이트는 update-signature(사용자 확인·PR·+1)
상태
B ☑ c73550f, A ☑ C1+D 보정, C·C′ ☑ (11/06)
